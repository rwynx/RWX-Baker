STUDIO TIPS & SHORTCUTS

RESIZE
Resize Images: Drag the corner handle on any image message in the conversation preview to freely adjust its display size (120px – 480px).
REORDER
Drag & Drop anywhere: Grab message bubbles directly on the chat preview (drag across any row) or grab items in the Layers list to reorder.
GROUP
Group Chats: Toggle Conversation to Group to pick multiple characters, set a custom group name, and switch speakers.
SEND
Quick Send: Press Enter in the message input bar to send outgoing messages instantly.
EDIT
Edit Messages: Click any message or layer to change its text, character, or type.
BACKUP
Backup Chat: You can use the Save JSON button to download a backup of your conversation. Use the Load JSON button to restore a previously saved conversation.
You can also drag and drop a JSON file anywhere on the screen to load it.
EXPORT
PNG Export Modes:
• Screen: Saves the current visible preview frame. Good for smaller conversations, it captures whatever is visible on the screen at the moment.
• Full Chat: Saves the complete conversation from top to bottom into one full screenshot. If your conversation is very long, consider using Multi-Page mode to break it into sequential screenshots.
• Multi-Page: Breaks long chats into sequential screenshots (RWX-Baker-1.png, RWX-Baker-2.png, ...-3.png etc.) with continuity overlap. This mode always captures the image with the last message of the previous image at the top, creating continuity between pages.
